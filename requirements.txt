# O Qt reproduz arquivos locais e URLs diretas de mídia por conta própria.
# O QtMultimedia já vem com PyQt6, portanto o reprodutor não exige dependência
# adicional. Porém, uma página do YouTube não é um arquivo de vídeo: o yt-dlp
# transforma o link em um fluxo que o Qt consegue reproduzir. Sem ele, o HUD
# continua reproduzindo arquivos e URLs diretas, e os links do YouTube são
# abertos no navegador com uma explicação, em vez de simplesmente falharem.
#
# Intencionalmente, esta é a ÚNICA dependência sem limite de versão. O YouTube
# altera o conteúdo que disponibiliza sem aviso, e o yt-dlp responde com novas
# versões. Um limite superior acabaria prendendo uma nova cópia do projeto a uma
# versão que o YouTube já não aceita — exatamente o contrário do objetivo desses
# limites. Mantenha-o atualizado: pip install -U yt-dlp

# ── Opcional: executar o assistente com seus próprios modelos ─────────────────
# ⚙ → ENGINE & PROVIDERS permite substituir o Gemini Live por seus próprios
# recursos de reconhecimento de fala, modelo de linguagem e voz — ou direcionar
# somente as solicitações em segundo plano do assistente para outro provedor.
#
# NÃO É NECESSÁRIO INSTALAR NADA PARA A MAIORIA DESSES RECURSOS. A comunicação
# com um modelo — Ollama, LM Studio, llama.cpp, vLLM ou uma API hospedada como
# Groq, OpenAI, DeepSeek ou OpenRouter — utiliza httpx, que já está listado acima.
# As vozes nativas do sistema (SAPI no Windows, `say` no macOS e espeak-ng no
# Linux) também não precisam de nenhum pacote Python.
#
# Há apenas dois componentes que precisam ser baixados, e ambos podem ser
# instalados com um clique nesse painel:
#
#   pip install faster-whisper   # reconhecimento de fala: Whisper na SUA CPU.
#                                # Não precisa de GPU nem de ffmpeg — as amostras
#                                # do microfone são enviadas diretamente.
#                                # Suporta cerca de 50 idiomas, detectados a
#                                # cada frase em vez de serem configurados.
#   pip install piper-tts        # síntese de fala: uma voz neural nesta máquina,
#                                # em cerca de 50 idiomas. Cada voz ocupa
#                                # aproximadamente 60 MB e é baixada sob demanda;
#                                # o assistente utiliza a voz correspondente ao
#                                # idioma que acabou de ouvir você falar.
#
# Esses pacotes também foram deixados de fora da instalação pelo mesmo motivo
# dos demais recursos opcionais desta seção: juntos, ocupam várias centenas de
# megabytes, e uma nova cópia do projeto que utiliza somente o Gemini não deve
# precisar baixá-los. Remover providers/ elimina todo esse recurso, e o aplicativo
# funciona exatamente como funcionava antes de ele existir.
